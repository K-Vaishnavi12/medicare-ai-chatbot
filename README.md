# MediCare AI Chatbot

Public demonstration chatbot for **MediCare AI – AI-Powered Healthcare & Digital Prescription System**.

Built from the MediCare AI project documentation and the MediCare AI Canva site design (teal branding, multilingual EN / HI / TE, safety-first guidance).

## Features

- Answers questions about the platform, users, AI role, sample doctors, appointments, digital prescriptions, privacy, and general care-navigation topics
- English, Hindi, and Telugu UI
- Clear safety messaging: informational only — no diagnosis or prescriptions
- No patient data stored; works fully in the browser

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
